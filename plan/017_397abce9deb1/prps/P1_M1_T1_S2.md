# PRP — P1.M1.T1.S2: Comparable (semver) version of the running binary

## Goal

**Feature Goal**: Provide a comparable (semver) representation of the *running binary's* version that is distinct from `main.resolveVersion()`'s display-only string, so `stagecoach upgrade --check` (FR-U6) and the direct-swap path (FR-U5 step 1) can compare the running version against the latest release tag. Implemented stdlib-only (no new Go dependency), matching the repo's minimal-deps posture.

**Deliverable**: A new file `internal/upgrade/version.go` (package `upgrade`, the first file of that package) exposing four symbols — `ParseAndClean(raw string) (string, bool)`, `Compare(a, b string) int`, `CurrentSemver() (string, bool)`, `SetCurrentVersion(v string)` — plus `internal/upgrade/version_test.go` (table-driven, mirroring `internal/exitcode/exitcode_test.go` style), and a one-line wiring change to `cmd/stagecoach/main.go` that pushes the raw ldflags `version` into the upgrade package. `main.resolveVersion()` stays byte-for-byte unchanged.

**Success Definition**: The contract test table passes (`Compare`: 1.0.0<1.0.1, 1.0.0==v1.0.0, 1.0.0>1.0.0-rc1, 2.0.0>1.9.9; `CurrentSemver`: ok=true for a release, ok=false for "dev"); `go test ./internal/upgrade/` is green; `resolveVersion()` is untouched; no new module dependency; `go build ./...` succeeds.

## Why

- `main.resolveVersion()` produces a **display** string (`"dev (19f4df7-dirty)"`) that is deliberately NOT comparable. FR-U5 step 1 ("Resolve current version ... §21.1") and FR-U6 (`--check` prints `X.Y.Z → Z` and exits 6 when behind) BOTH require comparing the running binary's version to a release tag — impossible with the display string.
- This is the **second** reusable primitive of Milestone P1.M1 (Foundation). The exit-code-6 primitive landed in P1.M1.T1.S1 (already complete: `UpdateAvailable=6`, `ErrUpdateAvailable` in `internal/exitcode`). The `--check` dispatcher (P1.M4.T2.S1) and the `--check` test suite (P1.M4.T3.S1, which injects "older/newer/unparseable" current versions) both block on `CurrentSemver` existing and being injectable.
- A dev build (`version == "dev"`) MUST report `ok=false` so `--check` prints current display + latest and does NOT claim an update is available (exit 0, informational). This PRP encodes that boundary: `CurrentSemver("dev")` → `("", false)` and `Compare` never lets an unparseable operand fabricate an "update available" result.

It adds **no** CLI flag, **no** config, **no** network, **no** filesystem write, and touches **no** commit-path code.

### Implementation Patterns & Key Details

```go
func ParseAndClean(raw string) (string, bool) {
    raw = strings.TrimSpace(raw)
    if raw == "" || raw == "dev" || strings.HasPrefix(raw, "dev ") {
        return "", false
    }
    raw = strings.TrimPrefix(raw, "v")
    raw = strings.TrimPrefix(raw, "V")
    if i := strings.Index(raw, "+"); i >= 0 { 
        raw = raw[:i]
    }
    core, pre, hasPre := raw, "", false
    if i := strings.Index(raw, "-"); i >= 0 {
        core, pre, hasPre = raw[:i], raw[i+1:], true
    }
    parts := strings.Split(core, ".")
    if len(parts) != 3 { return "", false }
    for _, p := range parts {
        n, err := strconv.Atoi(p)
        if err != nil || n < 0 { return "", false }
        if len(p) > 1 && p[0] == '0' { return "", false } 
    }
    if hasPre {
        if pre == "" { return "", false }
        for _, id := range strings.Split(pre, ".") {
            if id == "" || !validPreID(id) { return "", false } 
        }
        return "v" + core + "-" + pre, true
    }
    return "v" + core, true
}
func Compare(a, b string) int {
    ca, oka := ParseAndClean(a)
    cb, okb := ParseAndClean(b)
    if !oka || !okb { return 0 }
}

```
